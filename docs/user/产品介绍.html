ClickGit

面向不使用 Git 命令行的桌面工具，把常见版本管理流程整理为明确的界面状态和按钮操作。 从打开项目到处理冲突，全程支持完全点击操作。

Windows / macOS

日常工作流

01

打开与克隆

打开本地 Git 仓库，或填写远程地址克隆项目，并保留常用仓库入口。

02

检查与提交

查看文件变化和差异，选择需要记录的文件，填写说明后完成提交。

03

同步远程

通过拉取、获取和推送完成同步，操作前显示当前仓库和分支状态。

04

管理分支

创建、切换、合并和删除分支，减少分支名称与当前上下文混淆。

05

处理冲突

集中显示冲突文件，完成内容确认后再标记解决并继续合并流程。

06

恢复变更

按文件撤销未提交修改，并通过历史与储藏功能找回或隔离工作内容。

操作范围

仓库与历史

状态检查、提交历史、差异查看、标签、远程仓库与基础维护。

进阶项目结构

支持 Worktree、子模块、Git LFS 等常见工程场景。

凭据与隐私

调用系统 Git 和凭据能力，不要求把账号密码写进项目文件。

风险提示

对覆盖、删除和恢复等操作提供确认信息，保留可判断的操作结果。

产品原则

看得懂

使用仓库、文件、分支和同步等界面语言表达 Git 状态。

点得动

核心流程提供完整按钮入口，不要求记忆或输入命令。

可确认

执行前明确对象，执行后展示结果，异常时保留可处理信息。
