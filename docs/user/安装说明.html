ClickGit 安装说明

根据操作系统选择对应安装包。ClickGit 已自带 Windows 所需的 Git 运行环境，日常使用不需要输入 Git 命令。

Windows 安装版

  1. 双击 ClickGit-Windows-x64-Setup.exe。
  2. 按安装向导选择安装位置和是否创建桌面快捷方式。
  3. 完成安装后，从开始菜单或桌面打开 ClickGit。
当前安装包未进行商业代码签名。Windows 可能显示“未知发布者”，请确认文件来自项目的正式发布页并核对 SHA-256 后继续。

Windows 便携版

  1. 解压 ClickGit-Windows-x64-Portable.zip。
  2. 保持 ClickGit 文件夹内部结构不变。
  3. 双击文件夹中的 ClickGit.exe。

不要只复制 EXE。_internal 和 runtime 是程序运行所需内容。

macOS

Apple 芯片 ClickGit-macOS-arm64.zip
Intel 芯片 ClickGit-macOS-x64.zip
  1. 解压与电脑架构一致的 ZIP。
  2. 将 ClickGit.app 拖入“应用程序”。
  3. 首次启动若被系统拦截，在“系统设置 → 隐私与安全性”中确认打开。

macOS 版本使用系统中可用的 Git。可先安装 Apple Command Line Tools， 再启动 ClickGit。

首次使用

  1. 打开 ClickGit，点击“打开仓库”选择已有项目，或点击“克隆仓库”。
  2. 首次提交前，在设置中填写 Git 用户名和邮箱。
  3. 连接 GitHub 私有仓库时，按界面提示完成凭据或 SSH 配置。
  4. 执行提交、拉取或推送前，先确认当前仓库和分支名称。

建议在第一次同步前备份重要文件。发生冲突时先查看冲突列表， 确认内容后再标记为已解决。

卸载与数据

Windows 安装版

在 Windows“设置 → 应用”中找到 ClickGit 并卸载，也可以使用开始菜单中的 卸载入口。

Windows 便携版与 macOS

退出程序后删除 ClickGit 文件夹或 ClickGit.app 即可。

卸载 ClickGit 不会删除已经打开或克隆的 Git 仓库。删除仓库属于独立文件操作， 请在确认备份和远程同步状态后进行。

常见问题

Windows 提示 SmartScreen 未知发布者

当前安装包尚未进行商业代码签名，因此 SmartScreen 可能显示“未知发布者”。请确认安装包来自项目正式发布页，并将文件的 SHA-256 与 SHA256SUMS.txt 核对一致后再选择继续运行。

便携版打开后提示缺少文件

便携版必须完整解压后运行，不能直接在 ZIP 预览窗口中启动，也不能只复制 ClickGit.exe。 请保留 _internal、runtime 和许可证文件。

macOS 被 Gatekeeper 阻止打开

当前 macOS 应用未签名、未公证，Gatekeeper 可能阻止首次启动。确认文件来源后，在“系统设置 → 隐私与安全性”中找到 ClickGit 的拦截提示并选择打开。

Git LFS 操作不可用

Git LFS 需要额外安装。安装完成后重新打开 ClickGit，并确认当前仓库已经执行 Git LFS 初始化；普通提交、分支和同步功能不依赖 Git LFS。
