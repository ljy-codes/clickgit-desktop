# ClickGit v0.1.0 发布记录

- 发布日期：2026-07-28
- Windows Release：`windows-v0.1.0`
- macOS Release：`mac-v0.1.0`

## 发布附件

### Windows

- `ClickGit-Windows-x64.zip`

### macOS

- `ClickGit-macOS-arm64.zip`
- `ClickGit-macOS-x64.zip`

## 平台说明

- Windows x64：解压后运行 `ClickGit.exe`。发行目录内包含 PortableGit 和
  Git Credential Manager，不要求用户另行安装 Git、Python 或 Qt。
- macOS Apple Silicon：M1、M2、M3、M4 等 ARM64 Mac 使用
  `ClickGit-macOS-arm64.zip`。
- macOS Intel：Intel Mac 使用 `ClickGit-macOS-x64.zip`。
- macOS 发行包包含 ClickGit 应用运行时，但依赖系统可执行路径中的 Git
  及系统已配置的凭据助手。

## 主要能力

- 打开、初始化和克隆 Git 仓库。
- 查看文件状态与差异，暂存、取消暂存、丢弃修改并提交。
- 获取、拉取、推送和安全强制推送。
- 创建、切换、合并、变基和删除分支。
- 管理标签与贮藏，查看提交历史和 Reflog。
- 导入、导出补丁，查看和编辑文本冲突。
- 创建提交恢复点、恢复隔离文件并管理 SSH 密钥。
- 创建、列出和移除 Worktree。
- 管理子模块和 Git LFS。
- 提供重置、清理预览、完整性检查等仓库维护能力。

## 已知问题

- Windows 应用未代码签名，SmartScreen 可能显示未知发布者提示。
- macOS 应用未签名且未公证，Gatekeeper 可能阻止首次直接双击启动。
- macOS 用户必须下载与 CPU 架构匹配的附件，并确保系统能够运行 Git。
- 大型仓库的历史记录默认最多加载 200 条。
- 文本冲突编辑器按 UTF-8 保存；二进制冲突需要使用外部工具处理后暂存。
